# Результаты работы

Реализованы мобильный клиент Android/iOS, сервисы заявок, аналитики и классификации. У каждого сервиса собственные сборка, зависимости и развёртывание. Keycloak отвечает за вход и роли; изменения заявок доходят до аналитики через Kafka и transactional outbox. Логи и распределённые трейсы проходят через Collector в ELK.

Проверены реальные PKCE-входы трёх ролей, разграничение доступа, девять жизненных циклов заявок, история, CSV, асинхронная аналитика и обучение модели на отдельной проверочной выборке. Масштабирование проверено на двух репликах заявок, трёх аналитики и двух классификатора. В Elasticsearch подтверждены связанные логи и цепочка HTTP → producer → consumer.

Общий интерфейс проверялся через временную браузерную сборку: создание, классификация, назначение исполнителя, статусы, история, дашборд и экспорт. После проверки браузерный код удалён, остались запрошенные мобильные платформы. Flutter analyzer проходит без замечаний. Временные тесты, тринадцать проверочных заявок и модель удалены; приложение начинает работу с ручным выбором категории.

Основные исправления касались инициализации KRaft, стандартных scopes Keycloak, доступа сервисной учётной записи к Admin API, маршрутов OpenAPI и предотвращения повторного экспорта ошибок самого логирования. Подробности — в [.agent/errors.md](.agent/errors.md).

Android debug APK собран из окончательных исходников: `build/app/outputs/flutter-apk/app-debug.apk`. Повторный Flutter analyzer завершился без замечаний. Для сборки использованы локальные Flutter 3.50.1, Java 21 и Android SDK; системные настройки не менялись.

iOS-проект подготовлен, сборка требует macOS и Xcode. Запуск нативных плагинов на физическом устройстве не проверялся. Скриншоты и видео пользователь готовит самостоятельно.
